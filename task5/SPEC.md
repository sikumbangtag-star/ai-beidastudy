# Task5 Spec: 股票收益分类模型与 ROC/AUC 评估

## 1. 任务目标

第五次课堂作业主题为机器学习分类算法。本任务使用股票收益分类数据，构建二分类模型，预测应变量 `Y`，并评估模型分类效果。

核心流程：

1. 加载分类数据，使用资料区的股票收益数据，因变量为 `Y`，取值映射为 `0/1`。
2. 设定数据划分，将样本按日期前后分为训练集、验证集和测试集。
3. 构建并训练机器学习模型，包含线性回归、逻辑回归、决策树和随机森林。
4. 对模型进行评估，计算 AUC。
5. 绘制每个模型各自的 ROC 曲线，并在 HTML 面板中通过模型选择器切换展示。

最终成果以 notebook 和可复现输出文件为主，所有本次作业新增文件统一放在 `task5/`。

## 3. 字段与建模口径

标识字段：

- `Date`: 数据日期，按时间排序和切分时使用。
- `Code`: 股票代码，作为样本标识，不直接作为模型特征。

应变量：

- `Y`: 分类标签，原始值为布尔型。
- 建模时转换为整数标签：`False -> 0`，`True -> 1`。

候选特征字段：

- 估值类：企业倍数、PB、PCF、PE、PS、股息率、MV。
- 成长类：净利润同比增长率、净资产同比增长率、利润总额同比增长率、EPS 同比增长率、总资产同比增长率、现金净流量同比增长率、营业利润同比增长率、营业总收入同比增长率。

处理规则：

- `Date` 和 `Code` 不进入模型特征。
- 所有特征列转为数值型。
- 缺失值使用训练集的中位数填充，再应用到验证集和测试集。
- 极端值默认不删除；如需增强稳定性，可在后续实现中增加 1%/99% 分位缩尾。

## 4. 模型与评估设计

数据划分：

- 固定按日期前后切分，避免未来数据泄露。
- 先按 `Date` 升序排列；同一日期内可按 `Code` 升序排列，保证结果可复现。
- 前 `70%` 样本作为训练集，用于拟合缺失值填充参数和训练模型。
- 中间 `20%` 样本作为验证集，用于比较模型、观察参数效果和选择最终模型。
- 最后 `10%` 样本作为测试集，只用于最终 AUC、ROC 和辅助指标评估。
- 不使用随机切分；不使用测试集参与任何预处理参数拟合、模型训练或模型选择。

模型：

- 线性回归：作为分数型对照模型，输出连续预测值；用于说明回归模型也可以形成排序分数，但不是标准分类器。
- 逻辑回归：作为线性分类基准模型，输出正类概率。
- 决策树：作为非线性、可解释的树模型。
- 随机森林：作为集成树模型，用于和单棵决策树比较。

模型输出：

- 逻辑回归、决策树和随机森林在验证集和测试集上输出预测概率 `predict_proba[:, 1]`。
- 线性回归输出连续预测分数；计算 AUC/ROC 时将该分数裁剪到 `[0, 1]`，并作为正类概率近似。
- 根据默认阈值 `0.5` 生成预测类别。
- 保存每个样本的真实标签、预测概率和预测类别。

评估指标：

- AUC：核心评价指标。
- ROC 曲线：横轴为 FPR，纵轴为 TPR。
- 辅助指标：准确率、精确率、召回率、F1。

图表要求：

- 绘制目标变量 `Y` 的分布图。
- 绘制特征相关性矩阵，用于观察特征之间的线性相关关系。
- 为线性回归、逻辑回归、决策树与随机森林分别绘制独立 ROC 曲线。
- 每个模型都展示混淆矩阵、AUC、准确率、精确率、召回率、F1。
- 每个模型都展示对应特征分析：线性模型展示系数贡献，树模型展示分裂使用频次作为特征重要性近似。
- 添加随机分类参考线。
- 单模型 ROC 图保存到 `task5/outputs/figures/roc_<model>.png`。
- HTML 面板支持选择模型，选择后切换对应 ROC、混淆矩阵、指标和特征重要性图。
