# Task4 海龟策略量化分析 Spec

## 目标

Task4 使用前面课程已经下载的 5 只股票近两年日线数据和沪深300基准数据，实现海龟策略量化分析、交易信号计算、模拟交易回测和 HTML 可视化面板。

面板支持两个海龟策略版本切换：

- `20/10`：20 日高价通道突破买入，10 日低价通道跌破卖出。
- `55/20`：55 日高价通道突破买入，20 日低价通道跌破卖出。

## 策略口径

- 入场通道：判断日之前 `entry_window` 个交易日的最高价，不包含判断日，避免未来函数。
- 出场通道：判断日之前 `exit_window` 个交易日的最低价，不包含判断日，避免未来函数。
- 买入信号：空仓时，T 日收盘价突破 T 日可见的入场通道。
- 卖出信号：持仓时，T 日收盘价跌破 T 日可见的出场通道。
- 成交规则：T 日收盘判断信号，T+1 开盘价成交。
- 仓位规则：初始净值 `1.0`，单次满仓买入，卖出后空仓；不做金字塔加仓。
- 期末规则：最后仍持仓时按最后收盘价计算净值，不强制平仓。

## 成本与基准

- 买入成本率：`0.0005441`。
- 卖出成本率：`0.0010441`。
- 沪深300 `000300.SH` 作为基准，不作为交易标的。
- 股票和沪深300按共同 `trade_date` 对齐后再计算策略、基准和超额收益。

## 可视化面板

Task4 HTML 面板展示：

- 股票选择。
- 海龟策略版本选择：`20/10` 与 `55/20`。
- 入场周期和出场周期可用滑杆调节；版本选择作为快捷预设，切换版本时自动写入对应默认周期。
- 策略指标卡：策略累计收益、沪深300收益、超额收益、年化收益、年化波动、最大回撤、夏普比率、交易次数、胜率、平均持仓天数、总交易成本、突破/买入/跌破/卖出次数。
- 价格通道图：股价、入场高价通道、出场低价通道、买入信号、卖出信号。
- 净值图：策略净值、沪深300基准净值、超额收益曲线。
- 交易记录表：信号日、成交日、方向、成交价、成本率、交易后净值。

## 测试要求

- 验证 `20/10` 和 `55/20` 两个版本参数。
- 验证高低价格通道只使用判断日前历史数据。
- 验证突破入场后 T+1 开盘买入。
- 验证跌破出场后 T+1 开盘卖出。
- 验证买入和卖出成本率。
- 验证策略净值、沪深300净值和超额收益按共同交易日计算。
- 验证面板包含股票切换、版本切换、通道图、净值图、指标卡和交易表。

## ATR 补充口径

- 面板展示 `ATR(20)` 和 `ATR/收盘价`。
- 真实波幅 `TR = max(high - low, abs(high - previous_close), abs(low - previous_close))`。
- `ATR(20)` 为最近 20 个交易日 `TR` 的简单平均值。
- 当前版本中 ATR 作为波动观察指标展示，不参与仓位缩放或加仓规则。

## 布局补充

- 策略版本、入场周期和出场周期放在左侧控制栏调节。
- 顶部工具栏只保留股票选择、日期范围和导出按钮。
- 右侧内容区优先展示结果指标，然后展示价格通道图、净值图和交易记录。

## 成本与止损说明

- 左侧控制栏展示具体成本率：买入成本率 `0.0005441`，卖出成本率 `0.0010441`。
- 当前卖出/止损条件为：持仓时，判断日收盘价跌破出场低价通道，下一交易日开盘卖出。
- 通道模式不是 ATR 止损；在通道模式下 ATR 仅作为波动指标展示，不参与止损、仓位缩放或加仓规则。

## ATR 止损与仓位管理扩展

- 面板新增止损模式：`低价通道止损`、`ATR 止损`、`通道或 ATR 先触发`。
- ATR 止损价：`成交买入价 - ATR * ATR止损倍数`，默认 ATR 周期 `20`，默认止损倍数 `2.0`。
- ATR 仓位管理：`风险股数 = 账户净值 * 单笔风险比例 / (ATR * ATR止损倍数)`。
- 实际买入股数取 `风险股数`、`最大仓位可买股数`、`现金可买股数` 三者中的最小值。
- 默认单笔风险比例为 `1%`，默认最大仓位比例为 `100%`。
- 通道模式保持原满仓买入逻辑，便于和 ATR 风控版本进行对比。
